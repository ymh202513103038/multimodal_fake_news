# 真途 · 九十年
## ——用多智能体工作流，构建可溯源、可验证、可审计的长征记忆证据链

> **参赛方向**：红色记忆主题赛道（长征胜利 90 周年 · 1936—2026）
> **作品口号**：长征走的是征途，我们要走的是真途。
> **副口号**：每一段记忆，都有它来时的路。

---

## 一、作品概述

**《真途·九十年》**是一套面向长征胜利 90 周年的**智能考据与多源互证系统**。它以自研的多智能体采集与核查工作流为骨架，对网络流传的长征故事进行**"三层体检"**——过度丑化的予以驳斥、过度美化的予以校正、细节误传的予以还原——最终为每一个长征故事生成一张**《真途卡》**：史实等级、版本谱系时间线、三条体检结论与全部权威出处链接。全流程满足**可溯源、可验证、可审计**三项标准。

一句话定位：**别人用 AI 再现长征，我们用 AI 为长征建立证据链——让每一段红色记忆，都有它来时的路。**

核心立场：**尊重真实，就是最深的致敬。** 长征精神不需要神化——真实的它，比任何虚构版本都更有力量。

## 二、背景与痛点：90 周年之际，长征故事正面临"三种褪色"

2026 年是红军长征胜利 90 周年。纪念热度越高，网络上的长征叙事越混杂。我们归纳出三类正在让长征精神"褪色"的问题：

### 1. 过度丑化——谣言攻击真实战斗

以流传最广的**"飞夺泸定桥虚构论"**为例：网文宣称"川军根本没有抵抗、是主动放行"，甚至出现"红军逼老百姓当人肉盾牌"的恶意变体。
**查证结论**：这一说法与**敌方当事人**的记录直接矛盾——[人民网党史频道刊发的原川军将领回忆](https://cpc.people.com.cn/BIG5/n1/2022/0721/c443712-32481508.html#1)记载，守桥川军第 38 团李全山部奉命凭险固守、曾拆除部分桥板并向红军射击；中国互联网联合辟谣平台设有[专文辟谣](https://piyao.org.cn/2020-08/22/c_1210765008.htm)（《"飞夺泸定桥"是虚构的？红军逼老百姓当人肉盾牌？历史不容污蔑！》）；中央党校卢毅教授在《历史评论》发表[专文批驳](http://mp.weixin.qq.com/s?__biz=MzU1ODkwMjE1OA==&mid=2247494493&idx=1&sn=e791f08432ed548c0ae411efd75c12b0)；[CCTV 辟谣合辑](https://big5.cctv.com/gate/big5/news.cctv.com/2021/07/16/ARTIEiY92ubk4fJmFSR5IxIg210716.shtml)将"雷锋做好事是假？飞夺泸定桥战斗不存在？"并列为谣言。

### 2. 过度美化——注水的细节反而给质疑者递刀

以**"一昼夜奔袭 240 华里"**为例：网络上把红四团一昼夜 240 里的急行军渲染成"不可置信的神迹"，随之而来的是"人的生理极限不可能"的质疑——**质疑者拿的靶子，正是夸张版的宣传**。
**查证结论**：解放军新闻传播中心官方军网以专文正面回应——《[一昼夜奔袭 240 里，还是山路？这是必须创造的纪录！](http://www.81.mil.cn/yw_208727/16495812.html)》，给出路线构成、轻装急行、沿途换人等细节考证。**真实的 240 里已经是战争史上的极端纪录，不需要注水**。
同类案例：泸定桥"22 勇士"名单（[战斗真实，但大多数勇士姓名未能留存](http://jczs.news.sina.com.cn/2006-09-25/1709400894.html?from=wap)——真实的遗憾比虚构的完整更可信）。

### 3. 细节误传——记忆在传播中漂移 35 年

以**"半条被子"**为例：故事核心真实且有最高层级讲述（习近平总书记 2016 年在纪念长征胜利 80 周年大会上讲述），但流传版本中"徐解秀丈夫送红军后从此没了音讯"为误传——2019 年中国青年报[匡正报道](http://s.cyol.com/articles/2019-02/12/content_k0a5nlTo.html)证实：丈夫朱兰芳护送女红军后**五六天即返家**，误传源于 1984 年采访时语言不通，罗开富本人向记者证实；女红军住宿时长以[中央党史和文献研究院组织百名专家实地调查](https://news.cctv.com/2016/10/22/ARTIy4osSbBd50qPEr5zc6O9161022.shtml#1#1)后的 2018 年《经济日报》报道为准。
**危害**：一个采访误会，让当事人家庭背负了 35 年的错误家族记忆；错误版本传播了几十年，匡正版反而少有人知。**误传的危害不在惊天动地，在绵长。**

### 4. 危害总结

| 类型 | 直接危害 | 长期危害 |
|---|---|---|
| 过度丑化 | 抹黑英烈、否定真实战斗 | 动摇青年对整段信史的信任（"泸定桥是假的，长征还有什么是真的？"） |
| 过度美化 | 一处细节被戳破，全盘遭疑 | 为丑化者递刀；"被欺骗感"泛化为对红色教育的整体怀疑 |
| 细节误传 | 错误版本跑赢匡正版本 | 当事人家族长期背负错误记忆；史实层层失准 |

## 三、解决方案："真途"智能体工作流

### 3.1 系统流程

```
输入：任意一个长征故事的名称或叙事文本
        ↓
① 多通道文献采集（智能体自动执行）
   党史文献库 / 军网与权威媒体 / 地方志与纪念馆官网 / 学术考证文章
        ↓
② 事件簇归并
   同一故事的多来源、多时期、多版本记述 → 归并为一个"记忆单元"
        ↓
③ 三层体检（对簇内全部版本）
   丑化的 → 驳（跨阵营文献互证）
   美过头的 → 校（以官方考证回应）
   误传的 → 还原（给出匡正记录与版本谱系）
        ↓
④ 输出《真途卡》
   史实等级 + 版本谱系时间线 + 体检结论 + 全部出处链接
```

### 3.3 判定口径（长征版六分法）

| 标签 | 定义 | 示例 |
|---|---|---|
| 传谣（丑化） | 否定真实战斗、编造抹黑 | "泸定桥没打仗" |
| 夸大（过度美化） | 真实事件+注水细节 | "22 勇士全名单" |
| 版本漂移（误传） | 细节在传播中漂移 | 半条被子"丈夫失联" |
| 信实 | 有档案/实物/当事人互证 | "半截皮带"实物存军博；陈树湘断肠明志（党史记载） |
| 文学 | 艺术创作（标注属性，非史实亦非谣言） | 《金色的鱼钩》《七根火柴》（小学课文文学创作，"缝衣针做鱼钩"有真实原型类记载） |
| 待考 | 细节存在学术争议 | 泸定桥守军规模 |

## 四、已完成实证：这不是构想，是已验证的系统

### 4.1 母项目管线已在真实数据上全流程跑通

多智能体采集与核查工作流已在一个**平行的当代谣言域**（多模态战争谣言）完成全量验证：

- **四通道采集**：YouTube Data API + yt-dlp（每日定时收割）、X 双通道（twscrape + Chrome 真浏览器接管 27 工具直连）、新闻/核查站通用探测模板；
- **100 行真实数据全量打标**：覆盖 12+ 平台、45 个事件簇；
- **8 条金标准**：逐条访问网页 + 检索中英核查原文，每条带完整证据链 URL；
- **26 条已核簇**：同谣言家族直接套用核查结论（AFP / 澎湃明查 / RTVE / 新华社 / VRT / 军网等）。

### 4.2 方法论已在长征域完成"预演"

本文第二节的泸定桥、半条被子、240 里、金色的鱼钩四个案例，就是用同一套方法**实际完成核查**的成果——每一条都有可点开验证的权威出处。此外还发掘出"**将军让名**"的正面标杆：[人民网党史频道《从"十八勇士"的争定看孙继先将军品格》](http://dangshi.people.com.cn/n1/2016/1024/c85037-28803844.html#1)——孙继先拒绝把自己算进勇士名单（"我怎么能算勇士呢"），晚年杨得志上将出面还原（[人民网党史](http://dangshi.people.com.cn/n/2013/0315/c85037-20801382-2.html)）。**尊重真实、尊重英雄——英雄自己先选择了真实**，这正是本作品的主题注脚。

### 4.3 质量控制：三级状态 + 公开勘误

- 全部数据标注**三级状态**：已外查核实 / 已核簇 / 初判待核——不冒充、不含糊；
- 审计方法包含**对自身的勘误记录**：核查中发现的判定错误均公开修正并注明成因（时间换算、图注截断、检索语言偏向）——**连自己的错误都公开勘误，是科学态度的一部分**。

## 五、创新点

1. **事件簇归并方法**：把"一件事被切成多块"的碎片化传播，归并为可管理的事件单元（母项目 100 行→45 簇），解决谣言/记忆研究中最普遍的碎片化痛点；
2. **三层判定法**（事件层/素材层/表述层）：纠正"只做文本相似、不做事实分层"的行业通病——事件真≠画面真≠表述准，三层分离后，"默克莱""Xbox 激光"式复合案例不再被误判；
3. **中文核查源方法论**：核查检索必须覆盖主张的原始语言圈（本案例中中文核查源"澎湃明查"即为关键依据）；
4. **三级状态机**：已外查核实 / 已核簇 / 初判待核——质量控制透明可审计，不冒充、不含糊；
5. **首发"长征故事考据"结构化档案**：《真途卡》让每一个长征故事第一次拥有"史实等级 + 版本谱系 + 体检结论 + 全链出处"的标准形态。

## 六、社会意义与教育价值

- **捍卫真实记忆**：为涉长征谣言提供"识别—溯源—取证"的技术闭环，是[辟谣平台](https://piyao.org.cn/2020-08/22/c_1210765008.htm)与军网考证工作的数字化延伸；
- **服务红色教育**：《真途卡》可直接转化为教学资源——用考证的方式学历史，让青少年在"亲手验证"中理解"尊重真实就是尊重英雄"；
- **方法论示范**：公开"连自己错误都勘误"的工作记录，向青少年示范什么是诚实的考证态度——**方法本身即是教育**；
- **90 周年献礼**：以长征胜利 90 周年为契机，把散落的故事一砖一瓦固定下来——**把长征的路，重新走成一条"真途"**。

## 七、敏感性设计（伦理与边界）

1. **以权威定论为唯一锚点**：系统不自行判定历史结论，所有"真实事件结论"均引用权威文献、官方考证或司法判例；
2. **无官方结论者，一律"待考"**：不收录、不标注、不讨论暂无权威结论的说法；
3. **区分"文学创作"与"史实"**：对《金色的鱼钩》等课文，标注文学属性并给出真实原型记载——标注属性是保护，不是否定；
4. **遵守《英雄烈士保护法》**：涉英烈内容以官方结论与司法判例为准，不使用诽谤性原文。
