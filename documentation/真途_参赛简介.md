# 真途
## ——面向长征故事多模态虚假信息检测与溯源系统

> **参赛方向**：多模态虚假新闻检测 · 智能体工作流
> **系统口号**：长征走的是征途，我们要走的是真途。
> **副口号**：每一段记忆，都有它来时的路。

> **三层核查机制**（本方法命名）：对每条叙事文本依次执行**事件层**（史实是否发生）、**素材层**（画面与出处真伪）、**表述层**（归属与措辞）的分层核查——三层各有学界成熟的核查实践对应，组合框架为本作品提出。

---

## 一、系统概述

**「真途」**是一套**基于多智能体工作流的多模态虚假新闻检测与溯源系统**。系统以**调度主控**驱动四个职能智能体协同工作：

```
调度主控（LLM 驱动，决定搜什么、采哪条、何时停）
   ├─ 采集 Agent：四通道多模态素材采集
   ├─ 归簇 Agent：事件簇归并（一事一簇）
   ├─ 核查 Agent：三层核查（事件/素材/表述）
   └─ 出卡 Agent：《真途卡》结构化档案生成
        ↓
全流程满足【可溯源、可验证、可审计】三项标准
```

一句话定位：**别人用 AI 生成内容，我们用 AI 为内容建立证据链——让每一段记忆，都有它来时的路。**

---

## 二、背景与痛点：多模态虚假信息的"碎片化传播"

以真实数据为证（本系统已完成 100 条多平台谣言数据的全量核查）：

1. **一事切成多块**：同一虚假事件在多个平台以多种变体传播（某战果宣称的变体在数据集中占 10 行），传统"逐条检测"无法覆盖事件全貌；
2. **报道与传谣混杂**：可信媒体对真实事件的报道、单方宣称的渲染、辟谣内容在同一传播链中混杂——只做文本相似匹配的系统无法区分"报道某人说 X"与"断言 X 为真"；
3. **核查源单一化**：只检索英文核查源会漏掉中文核查结论，反之亦然。

## 三、已完成实证（真实数据，全部可验证）

- **四通道采集已跑通**：YouTube（Data API + yt-dlp 定时收割，配额账本 0 超支）、X 双通道（twscrape + Chrome 真浏览器接管 27 工具直连）、新闻/核查站通用探测模板（已验证辟谣平台与国际核查站）；
- **100 行多平台谣言数据全量打标**：覆盖 12+ 平台、归并为 **45 个事件簇**；
- **8 条金标准**：逐条访问网页 + 检索中英核查原文（AFP / 澎湃明查 / RTVE / 新华社 / VRT / 军网等），每条带完整证据链 URL；
- **26 条已核簇**：同谣言家族直接套用核查结论；
- **审计制度**：判定错误公开勘误并注明成因（含对自身审计方法的修正记录）。

---

## 四、核心方法创新

1. **事件簇归并方法**：把"一件事被切成多块"的碎片化传播，归并为可管理的事件单元（100 行→45 簇），解决"逐条检测"无法覆盖事件全貌的痛点；
2. **三层判定法**（事件层/素材层/表述层）：纠正"只做文本相似、不做事实分层"的行业通病——事件真≠画面真≠表述准；
3. **中文核查源方法论**：核查检索必须覆盖主张的原始语言圈；
4. **三级状态机**（已外查核实 / 已核簇 / 初判待核）：标注质量控制透明可审计；
5. **公开勘误的审计制度**：判定错误公开修正并注明成因——连自己的错误都勘误，是科学态度的一部分。

- **对平台**：为辟谣工作提供"事件簇+证据链"的技术补充，弥补"逐条检测"的盲区；
